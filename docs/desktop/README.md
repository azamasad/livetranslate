# Zeinab for Windows

These documents specify a Windows program that listens through the laptop microphone and shows English beside Persian. The program is not built yet. The page that opens from PowerShell is a separate product and stays as it is.

Read them in this order:

1. [Product requirements](prd.md) — who it is for, what it must do, and what "good enough" means on the Lenovo laptop.
2. [Technical design](technical-design.md) — the process, the models, the files on disk, and the privacy rules a build has to follow.
3. [Test cases](test-cases.md) — the checks that have to pass on that laptop before the program is handed over.

The machine these documents are written for is the one already in use: a Lenovo laptop, Intel Core i7-8565U (4 cores, 8 threads, up to 4.6 GHz burst, 1.8 GHz base), 24 GB RAM, Intel UHD Graphics 620, Windows 11. Inference is planned for the CPU. The graphics chip is not part of the design.
